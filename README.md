# ICID - Interactive Conversational Intelligence Dashboard for Business Insights

This repository contains a prototype for an intelligent Business Intelligence (BI) system designed to eliminate the technical bottlenecks associated with data retrieval. This application resolves the problem of  non-technical users to generate fully functional, interactive data dashboards using only natural language prompts.

By parsing plain English requests, the system autonomously executes the required database queries, selects the most optimal data visualization formats, and renders a cohesive dashboard in real-time.
